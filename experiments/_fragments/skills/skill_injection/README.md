# Skill Injection Skill Bundles

This directory owns repository-versioned skill content for the `skill_injection`
ablation. The bundle manifests in this directory are intentionally separate from
the experiment runner configs so each injected skill surface is explicit and
auditable.

The actual skill directories are planned work. Do not run non-control
`skill_injection` conditions until the referenced skill directories exist and
their phase roadmaps mark them complete.
